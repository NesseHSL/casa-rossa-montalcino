# Source files (not part of the website)

Nothing in this folder is published. The website is built from `src/` and `content/` only.

- `floorplans/make.py` redraws the three floor plans (ground floor, first floor, pool house).
  Run `python3 make.py` (needs Google Chrome installed), then copy the three PNGs it makes
  into `images/`.
- `guide/` holds Pat's how-to guide: the HTML source and the PDF made from it.
